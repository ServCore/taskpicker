# 我的任务 · 本地任务库

使用 **Go + Wails 2.16 + Vue 3 + TypeScript + Naive UI**，从腾讯文档筛选指定负责人的任务，连同图片保存在本机。读取、图片处理、Excel 导入和缓存均由 Go 完成。

## 启动与打包

```sh
make run       # 启动开发版，支持热更新；直接 make 也可以
make install   # 安装项目依赖
make test      # Go / 前端测试与 TypeScript 检查
make test-live # 使用自行配置的腾讯文档验证读取（需要联网）
make build     # 打包 dist/我的任务.app
make open      # 打开已打包的应用
```

源码开发需要 Go 1.26+、Node.js 22.12+ 和 Xcode Command Line Tools。首次运行自动安装固定版本的 Wails CLI 及前端依赖，也可双击 `启动.command`。

打包后的 `.app` 可独立使用，无需安装开发环境。当前构建架构与本机一致，为 Apple Silicon，目标 macOS 13+。`make build` 使用本机 ad-hoc 签名；向其他 Mac 分发时需按目标架构构建，并按分发要求签名、公证。替换的旧应用移到废纸篓，避免混入旧版依赖。

开发服务仅监听 `127.0.0.1`，Go 默认端口 34871；端口冲突时可用 `make run DEV_SERVER=127.0.0.1:34872`。生产版不启动开发 HTTP 服务。

## 浏览任务

- 左侧切换文档，已有本地内容立即显示，无需联网。
- 主界面默认只显示未完成任务列表，按原表顺序列出任务摘要、状态、配图缩略图、日期和原行号。支持全文搜索和按状态多选筛选。
- 点击任务后从右侧抽屉展示完整任务描述、备注、原始字段及所有配图；支持上一条 / 下一条、Esc 或点击遮罩关闭，关闭后回到列表。点击图片放大，可缩放、旋转、左右切换，也可使用键盘操作。
- 详情抽屉可修改任务状态，点击一次“同步”即可保存本地并回写远程；重启、离线或回写失败不会丢失已保存的修改。待回写的已完成任务仍显示在默认列表，远程回读确认后才隐藏。
- 首次点击“同步”时，如未授权，会自动打开腾讯文档授权页，使用拥有编辑权限的 QQ / 微信账号完成授权即可继续；也可在文档设置中提前授权。普通表格按原行号并核对任务内容、负责人和状态列；智能表按记录 ID 定位，旧缓存使用唯一内容匹配。远程状态冲突、行列变化、无法唯一定位或公式状态列会停止写入。每次仅回写一个任务的状态，成功后回读核对；失败可重试或撤销本地修改。
- 有待回写修改时，重新读取会被阻止，请先回写或撤销，避免覆盖本地修改。
- 列表支持上下方向键，搜索默认仅显示放大镜，点击或按 `⌘F` 展开并聚焦搜索框，按 `Esc` 清空并收起；详情工具栏支持复制文字、打开原表及切换上一条 / 下一条任务。
- “添加在线文档”只需选择项目、填写链接；先识别链接所指工作表的表头，再进入文档设置配置条件并手动同步。已有文档再次添加会直接打开，保留原有配置。也可导入含图片的 `.xlsx`，多工作表文件支持切换。
- 文档设置中集中配置拉取条件，点击“保存文档设置”后保存在本机，顶部仅展示文字摘要，手动、启动与定时拉取共用；修改后显示“条件已修改，待同步”。拉取仅按已配置条件匹配，不额外排除已完成、已修复或已关闭的任务；未设置条件时拉取全部任务。需要限制状态时可添加状态列条件，下方多选状态筛选只影响本地展示。
- 同步有进度显示，可以取消；读取或下载图片失败时保留原缓存。
- 重启恢复上次打开的文档和工作表，详情抽屉默认关闭，离线时仍可浏览所有已保存的图片。

首次使用请创建项目并添加自己的腾讯文档链接，或导入 Excel。发行源码不包含真实文档链接、默认负责人或任务缓存；已有本地快照仍可读取。

## 项目与本地目录

左侧按项目组织文档，旧版项目配置继续兼容，首次启动会创建可改名的默认项目。点击项目名称或左侧箭头收起、展开，重启后保留状态。点击项目旁的设置按钮，可改名、添加多个本地目录、开启或关闭本项目的日报；新项目默认关闭日报，已有项目保留开关状态。文档归属在添加在线文档时选择，或通过文档设置调整。目录可分别绑定前端、后端等项目；打开目录按钮会在多个目录之间提供选择。移除目录只解除关联。

每个项目有自己的「工作日报」入口，点击后在主区域打开独立页面，与任务列表切换显示；按项目和日期分别保存正文、续写进度及日报提示词；AI 连接、Key 和模型仍在独立的 AI 设置页共用。仅汇总本项目的记录，文档移组后此前已记录的工作仍属于原项目；关闭日报后隐藏入口，关闭期间的操作不纳入日报，已有正文和记录保留，重新开启即可继续查看。升级前的记录按文档归属兼容；原 `yiqiban` 项目的旧日报在来源记录全部属于该项目时自动复制到项目日报，旧文件原样保留。

点击项目旁的「+」可以添加多份在线文档，每次选择所属项目；未分配的文档显示在「未分组」。右上角齿轮统一管理项目归属、来源链接、拉取条件与回写授权，任务列表顶部仅展示条件文字摘要。任意表头（含空白或重名列，显示列号）均可添加文字条件：等于、不等于、包含文字、不包含文字、包含成员、为空、不为空；同一工作表的条件全部满足才保留。负责人不再必填，旧文档保留原负责人筛选，编辑时转换为可移除的“包含成员”条件，保持完整姓名和多人单元格的匹配语义。修改条件保留文档身份、项目归属和操作历史；有待回写状态或备注时须先回写或撤销。

条件改变在下一轮同步时生效，不会立即过滤或覆盖旧缓存。点击“保存文档设置”保存条件，保存失败保留编辑内容并显示错误，返回则丢弃未保存修改。文档设置中的条件决定读取范围，下方搜索和多选状态筛选只影响本地展示。首次识别后尚未手动同步的文档不会参与启动或定时拉取，避免未配置完成就自动读取。

项目设置单独保存在 `library/projects.json`，文档条件保存在 `library/document-pulls.json`，项目日报和提示词保存在 `library/projects/<项目 ID>/` 下。重新同步和重启会保留这些配置。

## 读取逻辑

公开表格使用腾讯文档向访问者提供的数据接口，无需手动导出。普通表格使用有大小边界检查的 protobuf 数据池解析；智能表格解析字段、选项、记录与行列顺序。自动分页，智能表格若记录缺失会报错，避免只读取前 60 行。

链接的 `tab` 决定工作表；智能表格的 `viewId` 用于列顺序，检查全部记录，不受视图自身筛选条件限制。新文档不依赖负责人列来读取；智能表使用字段行，普通表格和 Excel 在前 100 行优先识别常见任务表头，未知列名回退到首个多列非空行，适用于单行表头、一行一条记录的表格。多层交叉表与复杂合并表头仍可能需要整理原表。已有负责人条件继续按完整姓名匹配，支持一行多人负责，“王小明明”不会误匹配。

新增条件按已解析的单元格展示文字比较，数字与日期目前也使用文字规则；不调用 AI 分析或生成代码。字段唯一时允许按同名表头重新定位移动的列，重名或空白列按所选位置绑定；失效字段或工作表会停止同步并保留旧缓存，不会静默取消条件。初次识别只请求首段结构数据，不继续翻页拉取全部任务，也不下载图片。

在线图片仅下载符合拉取条件的任务内容，携带腾讯要求的 Referer。网络请求和下载支持取消、超时及大小限制。验证图片后保留 PNG 原数据，其他支持的格式转为 PNG。所有图片成功后才原子更新快照；图片缺失、未知单元格类型会显示提示。

需要登录的文档会通过 Go 的 Chrome 协议客户端打开独立登录窗口，使用本工具专属的浏览器资料目录，登录后通过有权限的会话读取同一数据接口。需要安装 Google Chrome；不会复制或读取用户日常 Chrome 资料。公开读取已经实测，登录读取由于缺少私有文档账号尚未实测。也可以在文档中导出 Excel 后使用软件的“导入 Excel”。

Excel 导入支持合并负责人单元格、浮动图片、`DISPIMG + cellimages.xml` 图片，保留原始行号和图片归属。无法确定所属行的图片、外链 `IMAGE()`、新版 rich-data 图片等会提示。在线合并单元格及其他智能表格附件/图片字段格式尚未全面适配。读取与 Excel 导入不修改源文件、不执行公式。在线任务的状态回写需另行授权腾讯文档，仅修改对应任务的状态和备注字段；源 Excel 暂不支持回写。

## 本地数据

macOS 保存在：

```text
~/Library/Application Support/TaskPicker/library/
```

每个链接和负责人组合独立保存，包含 JSON 快照与真实 PNG 文件。图片从本地路径加载，不依赖在线图片链接。姓名匹配方式和文档键与旧快照兼容，无需重新导出。清理项目源码和构建产物不会删除这里的数据。

默认测试不访问网络，也不打开浏览器。`make test-live` 单独检查真实文档和离线图片读取。

## 状态回写授权与验证

授权使用腾讯文档官方 OAuth 2.0 + PKCE，通过系统浏览器完成；仅请求 `docs:read` 和 `docs:write`。令牌只存放在本机数据目录下的 `remote-auth.json`（仅当前用户可读写），不传给前端、不打入应用包；过期时尝试刷新，可在设置中重新授权。

`TASKPICKER_LIVE_STATUS_WRITE=1 go -C desktop test ./internal/app -run '^TestLiveStatusWriteSameValue$' -v` 是显式开启的联网写入测试：对自行配置且已缓存的原表，各选一条可唯一核对的任务，将现有状态按原值写回并回读，不改变任务业务状态。默认测试不执行远程写入。

2026-10-16 实测：普通表格第 4 行“暂不处理”、智能表第 45 条“进行中”均按原值写回并回读通过。接口不提供原子条件写入，本工具会在写入前检查远程原状态、写入后回读；检查与写入之间仍可能存在并发修改窗口。

窗口右下角显示应用主进程的 CPU 与驻留内存，每 2 秒刷新；不包含 WebView 辅助进程。CPU 100% 表示占满一个核心，首次采样或读取失败显示「—」。统计通过 macOS 原生接口在本机完成。

应用启动后会依次同步腾讯文档，沿用各文档保存的拉取条件，不额外按完成状态排除任务。底部状态栏显示当前文档、队列进度与读取阶段，右侧保留 CPU / 内存；可取消整轮同步。单份失败继续下一份，失败或跳过原因可悬停查看。已有待回写状态或备注的文档会跳过，本地 Excel 不自动重读；需要登录时提示手动同步，不在启动时弹出登录窗口。同步期间保留当前文档和搜索条件，可以继续浏览缓存。

「设置 → 项目管理」可启用或停用项目，保存后立即生效。停用项目及其文档、日报入口在左侧栏目隐藏，文档不会变为未分组；数据和归属保留，可在项目管理中重新启用。已有配置及新建项目默认启用，状态跨重启保留。

侧栏底部「设置」打开配置弹窗，左侧切换「AI 设置」「定时任务」与「项目管理」，右侧编辑对应配置；有未保存修改时需先保存或放弃，再切换或关闭。「定时任务」可按项目新建文档拉取计划，每个项目一条，可设置整数分钟 / 小时 / 天（1 分钟至 30 天），支持编辑、暂停 / 恢复、立即拉取和删除。每轮按项目当前归属依次拉取在线文档，沿用各文档自己的条件，本地 Excel 不自动重读；不会调用 AI 执行任务或回写远程状态。底部状态栏显示当前文档和队列进度，可取消整轮；失败继续下一份，有待回写状态或备注的文档跳过，需要登录时记录失败而不弹授权窗口。页面显示上次完成时间、结果和下次执行时间。

定时器仅在软件运行期间生效，关闭软件后不在后台运行；保存、恢复或一轮结束后，从该时刻等待完整间隔再执行。重启或休眠恢复遇到过期计划时，每个项目只执行一轮，不补跑错过的每一次。多个项目共用现有同步队列，遇到其他同步、任务详情、配置弹窗或未保存的页面编辑时会等待。暂停只停止后续轮次，当前轮次可用状态栏取消；暂停期间也可立即拉取。配置和最近结果持久化于 `library/sync-schedules.json`，删除计划不影响项目、文档或操作历史。

任务详情支持编辑原表的备注列（包括空白备注），支持多行、清空备注与仅同步备注。点击同一个「同步」按钮保存本地状态和备注并回写原文档；撤销会同时恢复两者。回写前检查所有待改字段的原值与任务身份，先写备注再写状态，并逐字段回读确认；服务端未提供跨字段事务，部分成功后可重试，已确认的值不会重复提交。失败与待同步修改会保存，启动同步会跳过对应文档。

`TASKPICKER_LIVE_NOTE_WRITE=1 go -C desktop test ./internal/app -run '^TestLiveNotesWriteSameValue$' -v` 可显式验证两类原表备注的原值写回与回读，不插入测试文本、不改变任务状态。

列表顶部的任务状态筛选支持多选，展示符合任一所选状态的任务；清空选择显示全部状态。选择会按文档、工作表自动保存在本机，切换、同步和重启后恢复，清空选择也会保存。“未完成任务”保留为快捷选项，包含待回写任务。状态选项包含原表选项及缓存任务的实际状态，与搜索共同生效，仅影响本地展示。原“不查看”功能及其排除规则已移除。

原表含紧急程度、紧急状态、优先级等字段时，列表增加对应一列，详情同步展示；多个字段分别保留原名和原值。紧急 / P0 用红色标签，高 / P1 用橙色，中 / P2 用蓝色；普通、低或未知值保持灰色，「不紧急」不会误标红。空值显示「—」，没有此字段的工作表不占列。复制任务文字也包含这些字段；今日截止置顶规则保持不变。

图片使用三档加载：列表显示最长边 144 px 的缩略图，详情显示最长边 960 px 的预览图，点击放大才加载原图。原始 PNG 与导出内容保持不变，显示缓存保存在各文档的 `thumbnails/` 和 `previews/` 下；旧快照首次打开时自动补建。图片转换同时最多运行 2 个任务，已保存的图片字节立即解除引用，同步/导入结束后主动回收临时 Go 堆内存。右下角仍显示主进程 RSS，未调整统计口径；WebView 辅助进程需另外计算，不能将主进程读数当作整个应用总内存。

未完成且截止日期为今天的任务置顶，以浅红底色、红色左边线和「今日截止」标记提醒，详情中也显示标记。置顶组内与其余任务分别保留原表顺序，继续遵守搜索和状态筛选。支持截止日期/时间、计划结束时间、预计修复时间等截止字段；测试时间与计划开始时间不触发提醒。按电脑本地日期判断，跨午夜及窗口重新获得焦点时自动刷新，不对已完成任务发出提醒。

底部状态栏按本机时间显示作息：08:30–11:30 倒计时距离午饭还有多久，11:30–13:30 显示「午休时间」，13:30–17:30 倒计时距离下班还有多久，其余时间显示「非工作时段」。倒计时每秒更新，午休及非工作时段只在下一时间边界更新；窗口隐藏时暂停计时器，返回后校准。

侧栏项目下的「工作日报」按本地日期汇总本项目文档的任务操作。自此版本起，状态与备注的实际修改、撤销、远程同步成功或未确认都会自动记录；仅查看、无变化的保存和启动拉取不会记录。任务详情的「工作进展 → 记入日报」可补充实际工作，仅保存到本机，不写入腾讯文档。记录保存操作时间、任务文字快照和字段前后值，与任务修改在同一次原子写入中保存；重新拉取或任务完成后从列表消失，不会清除历史。历史保存在文档 snapshot 的 activities 字段，普通任务库接口不加载历史到前端。

日报可按日期查看、生成本地草稿、编辑和复制；正文在点击「保存修改」、切换日期或页面时保存到 `library/projects/<项目 ID>/daily-reports/YYYY-MM-DD.json`，保存失败时保留正文并留在当前页面。已有正文时可使用「补充本地草稿」或「AI 续写日报」，读取最新操作并仅把尚未纳入的工作追加到末尾，保留已有正文和人工编辑；按操作 ID 去重，没有新增记录时不会调用 AI。仍可通过下方「重新生成」入口整体重做，重新生成会提示替换当前正文，生成失败、取消或生成期间正文另行改变时保留原稿。日报不会自动发送给他人，也不会自动提交到文档。

侧栏底部「设置 → AI 设置」配置 AI 使用的 API 基础地址、模型 ID 和 API Key，按兼容 Chat Completions 的接口调用（如 [DeepSeek 接口文档](https://api-docs.deepseek.com/api/create-chat-completion/)）。地址包含服务商要求的 `/v1` 等前缀，应用追加 `/chat/completions`；本机服务可填写 `http://127.0.0.1:端口/v1`。没有 AI 配置也能使用记录与本地草稿。自定义提示词在「工作日报 → 日报提示词」内单独编辑和保存，只作用于 AI 生成日报；修改模型连接不会改动日报提示词，修改提示词也不会改动模型连接。

日报整理的 AI 仅在用户点击生成或续写时调用，不在启动或操作任务时自动上传。发送内容为所选日期的任务文字、状态与备注操作、手动工作进展及自定义提示词，不包含图片、原文档链接、本地路径、腾讯授权或其他日期记录。Key 存在应用数据目录的 `daily-ai.json` 中（文件权限 600，未加密），不回显到前端；更换地址必须重新填写或清除旧 Key，HTTP 重定向不会携带凭据继续请求。请求超时为 120 秒，可取消；输入上限 512 KiB，响应上限 1 MiB，不完整输出不会覆盖日报。AI 生成结果仍需核对。操作记录从安装新版本后开始，不补录过去的操作。

任务详情中的「AI 执行任务」支持手动启动单个开发任务。第一版使用本机已安装并登录的 Codex CLI，沿用其模型与连接配置，独立于日报的 AI 配置；无需在软件中再次填写 Codex 凭据。可从项目绑定目录及两层子目录中选择 Git 仓库，补充执行要求后启动。已有未提交修改时会停止并提示整理，随后基于 HEAD 创建独立 Git worktree 和 `taskpicker/<执行 ID>` 分支，原目录的文件保持原样。AI 可定位问题、修改代码和运行验证，使用 workspace-write 沙箱，命令网络访问关闭，不能交互授权的命令会失败并在日志中显示。提示词要求优先查询所选原仓库中已有的 CodeGraph 索引，以当前工作区文件为准，不初始化、重建或升级索引。

每轮保存准备、运行、停止、失败或结束状态，记录 AI 任务理解、关键进展、执行结果和工作区累计修改文件，不记录逐行命令输出或内部推理。详情中的「执行文档 / 任务进展 / 修改文件」可以查看历史文档和任务当前摘要，修改文件页签可打开独立工作区。底部状态栏显示本次执行，关闭详情后执行继续；点击「停止执行」会停止执行进程及其子进程，已有工作区和记录保留。应用退出时取消执行；异常中断的记录在下次查看时标记为中断。每次最多执行 45 分钟，当前限制整个应用同时运行一个任务。

每次执行独立保存 `library/task-executions/<执行 ID>/report.md`，包含用户原文（任务内容及补充要求）、AI 理解、执行过程关键节点、最终结果与修改文件。执行时持续更新，停止、失败和中断也保留文档。任务详情按次数列出历史记录，可逐次预览、复制 Markdown 或打开本地 MD 文件，不再显示逐条命令和源码输出。旧记录按已有内容整理，未保存的 AI 理解明确标注缺失，不额外调用模型补写。元数据与内部事件保存在同目录的 `run.json`、`events.jsonl`。独立执行的工作区在该轮目录的 `workspace/`；继续处理复用所属链路最初一轮的工作区，每轮的元数据和 MD 仍分开保存。关键节点最多保留 120 条（开始节点与最近进展），最终结果最多 64000 字节，超出时标注截断。执行结束表示 AI 本轮结束，结果需核对；不会自动合并、提交、部署或回写远程任务状态。暂不提供自动执行队列或跨仓库协同。

「继续处理」承接当前选中的历史记录，保留同一工作区与分支中的已有修改，自动将最初任务、最初补充要求、累计进展摘要、本次要求和历史 MD 入口带入新的 AI 调用。它使用应用层摘要恢复上下文，不依赖 CLI 会话恢复，也不会发送全部原始日志；摘要作为历史事实使用，模型仍须核对当前代码。每轮结束要求 AI 更新简洁的累计摘要，旧记录或中途停止没有专门摘要时按已保存结果、关键节点和已有摘要回退整理，不另发模型请求。接续摘要最多 16000 字节，提供最近 12 轮及最初一轮的历史文档入口，需要细节时读取对应 MD。任务摘要持续保存在 `library/task-executions/tasks/<任务 ID>/progress.md`，可在「任务进展」页签查看、复制或打开。每轮 `report.md` 也保存当轮带入的上下文与输出摘要，历史文档保持当轮快照。

「重新执行」从所选原仓库当前提交建立新工作区和新处理链路，保留旧记录与工作区，重新执行仍要求原仓库没有未提交修改；继续已有工作区不要求原目录干净。同一任务曾经重新执行过时，可以选择旧链路的最新记录继续，摘要仅承接该链路，不混入其他工作区的结果。同一工作区只能继续其最新一轮；工作区丢失、分支变更、仓库解绑或记录不匹配时给出提示，不自动重建或丢弃修改。任务当前摘要跟随最近一次启动的链路，查看旧记录不会将其回滚。

## 联网测试配置

普通测试全部使用虚构示例。联网读取和原值回写测试需要设置 `TASKPICKER_LIVE_DOCUMENTS_FILE`，指向源码目录外的 JSON 文件（或被忽略的 `*.local.json` 文件）：

```json
[
  {"title": "自己的测试表", "source_url": "https://docs.qq.com/sheet/YOUR_DOCUMENT_ID?tab=YOUR_TAB", "owner": "自己的姓名"}
]
```

例如 `TASKPICKER_LIVE_DOCUMENTS_FILE=/absolute/path/documents.local.json make test-live`。回写测试也读取这个配置，并继续要求对应的显式写入开关、已缓存文档和编辑授权。不要提交真实文档链接、API Key、登录资料或业务缓存。
